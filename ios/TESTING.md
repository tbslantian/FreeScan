# FreeScan iOS 真机测试清单

目标设备：iOS/iPadOS 17 或更高版本的 iPhone、iPad。测试包必须签名后才能安装；当前没有配置 Apple 签名资料，尚未生成可直接安装的签名 IPA。正式产物仍以 App Store Connect IPA 为目标。

## 当前已知差异

- “增强”“柔和增强”仍为 Core Image 近似实现，其余基础滤镜及亮度/增强灰度已移植对应处理路径。
- 导入的 PDF 会渲染为图片后编辑，不保留原始矢量内容。
- 彩色笔迹擦除可能影响彩色印刷内容，不能自动识别黑色手写字。
- 原生算法测试已经覆盖部分合成样本；相机、文件提供器、打印、内存和识别效果仍需实机验证。

## 首轮测试

| 模块 | 操作 | 检查结果 |
|---|---|---|
| 扫描 | 允许相机权限，拍摄、重拍和连续拍摄三页 | 实时画面、边框、页数和缩略图正确 |
| 相册 | 多选照片，分别启用和关闭自动裁边 | 裁边路径生效，关闭后保留原始边界 |
| 证件 | 切换九个模板，完成正反面拍摄 | 取景框和提示对应模板，无一寸/二寸证件照规格混入 |
| 编辑 | 拖动四角、旋转、文字行倾斜校正、切换滤镜 | 当前页更新；其他页、原图模式和页面顺序正确 |
| 文档 | 导入横竖混排 PDF，保存后重新打开 | 每页方向和内容完整，文件名和顺序正确 |
| 水印二维码 | 测试夸克页脚及其他二维码，审阅候选后擦除 | 夸克兼容路径保留，正文没有误擦 |
| 试卷擦除 | 彩笔擦除、手动涂抹、撤销、重做、原图对比 | 结果、画笔范围和撤销顺序正确 |
| Vision OCR | 识别中英文页面 | 结果可选中复制，识别期间有进度提示 |
| Tesseract OCR | 下载启用 `chi_sim`、`eng` 后断网识别 | 可离线联合识别；取消下载、停用和删除语言包可用 |
| 导出 | 多页 JPEG、可搜索 PDF、指定 Files 文件夹 | 分享包含全部图片；PDF 可搜索选择，画面没有隐藏层文字叠印 |
| 打印 | iPhone、iPad 分别打开 AirPrint | 预览、纸张方向和弹出界面正常 |
| 恢复 | 扫描后退出并重新打开应用 | 未完成页面及文件夹访问权限正确恢复 |

出现问题时记录设备型号、系统版本、包版本/构建号、操作步骤、是否联网及对应原图和结果图。保留原文件，避免只用截图评估处理质量。
