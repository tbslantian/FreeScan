# FreeScan iOS 真机测试清单

目标设备：iOS/iPadOS 17 或更高版本的 iPhone、iPad。测试包必须签名后才能安装；当前没有配置 Apple 签名资料，尚未生成可直接安装的签名 IPA。正式产物仍以 App Store Connect IPA 为目标。

## 测试包与安装

在 GitHub Actions 手动运行 `iOS IPA`，将 `delivery` 选择为 `unsigned-device-test`。构建成功后下载 `FreeScan-iOS-Unsigned-Device-Test-<构建号>`，解压 GitHub 提供的 ZIP，得到 `.ipa`、`READ-ME-FIRST.txt`、`BUILD-INFO.json` 和校验文件。

这个包是未签名的真机测试包，不能直接点击安装。可以在个人电脑上通过本机签名工具使用自己的 Apple 账户签名侧载；Windows 的具体安装和开发者模式步骤可参阅 [AltStore Classic 官方指南](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)。账户和密码只在自己电脑的签名工具中输入，不上传到 GitHub 或聊天中。免费个人账户的配置描述文件有有效期限制，需定期重新签名，见 [Apple 官方说明](https://developer.apple.com/help/account/basics/about-your-developer-account)。

要生成 TestFlight/App Store 产物，选择 `app-store-connect` 并先配置 Apple 分发签名；该流程不会自动改发未签名包。

## 当前已知差异

- 含扫描全能王参考模型的真机测试包需要按 [参考模型构建步骤](porting/CAMSCANNER_IOS_PORT.md) 单独构建。
- 导入的 PDF 会渲染为图片后编辑，不保留原始矢量内容。
- 彩色笔迹擦除可能影响彩色印刷内容，不能自动识别黑色手写字。
- 原生算法测试已经覆盖部分合成样本；相机、文件提供器、打印、内存和识别效果仍需实机验证。

## 首轮测试

| 模块 | 操作 | 检查结果 |
|---|---|---|
| 扫描 | 用 iPad 横竖拍摄白纸和斜拍试卷 | 全屏预览方向正确，拍一张后自动处理并打开新页的编辑器 |
| 曲面与方向 | 用参考模型版拍摄旋转试卷、平纸与弯曲单页书页 | 高置信度文字方向自动转正，平纸维持直线，弯曲页可展平 |
| 相册 | 多选照片，分别启用和关闭自动裁边 | 与拍照共用处理逻辑，关闭后保留原始边界，导入后进入编辑 |
| 证件 | 切换九个模板，完成正反面拍摄 | 取景框和提示对应模板，无一寸/二寸证件照规格混入 |
| 编辑 | 重新拖动裁边四角、旋转、校正倾斜文字、切换滤镜 | 可在原片上调整裁边，增亮、增强锐化、智能高清、省墨的效果可区分，预览与导出走相同处理 |
| 文档 | 导入横竖混排 PDF，保存后重新打开 | 每页方向和内容完整，文件名和顺序正确 |
| 水印二维码 | 测试夸克页脚及其他二维码，审阅候选后擦除 | 夸克兼容路径保留，正文没有误擦 |
| 试卷擦除 | 彩笔擦除、手动涂抹、撤销、重做、原图对比 | 结果、画笔范围和撤销顺序正确 |
| Vision OCR | 识别中英文页面 | 结果可选中复制，识别期间有进度提示 |
| Tesseract OCR | 下载启用 `chi_sim`、`eng` 后断网识别 | 可离线联合识别；取消下载、停用和删除语言包可用 |
| 普通导出 | 分别关闭和开启 OCR，再导出 12 页 PDF 和多页 JPEG | 普通导出不等待识别，页数和顺序正确，分享包含全部页面，文件可复制到选定的 Files 文件夹 |
| 手动 OCR | 开启 OCR，在页面编辑里识别本页文字并生成可搜索 PDF | 本页文字可复制；可搜索 PDF 有识别进度，画面没有文字叠印，识别失败的页面仍保留图像 |
| 打印 | iPhone、iPad 分别打开 AirPrint | 预览、纸张方向和弹出界面正常 |
| 恢复 | 扫描后退出并重新打开应用 | 未完成页面及文件夹访问权限正确恢复 |

出现问题时记录设备型号、系统版本、包版本/构建号、操作步骤、是否联网及对应原图和结果图。保留原文件，避免只用截图评估处理质量。
