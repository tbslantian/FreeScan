## Contributing

Thanks for your interest in contributing to FreeScan.

### Issues

Please report bugs and feature requests in the GitHub Issues page. Describe the device, Android version, steps to reproduce the issue, and what you expected to happen. Before attaching document images or logs, remove personal or confidential information.

### Pull requests

- Keep changes focused and explain the problem they solve.
- Include steps to reproduce and verify behavior changes.
- Discuss large changes in an issue before starting implementation.
